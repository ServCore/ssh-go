# 项目介绍与简历素材

## GitHub 项目简介

**仓库名：** `ssh-go`

**About 描述：** 基于 Go、Wails 和 Vue 3 的桌面 SSH / SFTP 客户端，支持多标签终端、双栏文件管理、端口转发和传输中断恢复。

**建议 Topics：** `go`、`wails`、`vue3`、`typescript`、`ssh`、`sftp`、`desktop-app`、`terminal`。

## 简历：Go 后端方向

**ssh-go｜Go / Wails / Vue 3 桌面 SSH 工具｜个人项目**

- 开发 Go SSH / SFTP 后端，支持密码、加密私钥和 SSH Agent 认证、多层跳板机逐跳指纹校验，以及多会话终端和本地端口转发。
- 实现限制并发的传输队列、context 取消、暂存提交和分阶段恢复日志，处理覆盖冲突、迟到结果与连接关闭时的资源回收；为终端输出增加字节确认与流控。
- 使用本地隔离 SSH / SFTP 服务验证协议行为，后端通过 Go 竞态检查，配合 41 项 Playwright 界面回归验证连接、终端、传输与恢复流程。

## 简历：全栈方向

**ssh-go｜Go + Vue 3 桌面客户端｜个人项目**

- 使用 Go / Wails 与 Vue 3 / TypeScript 构建 SSH 工作台，实现服务器卡片、详情抽屉、多标签终端、双栏 SFTP 和文件传输队列。
- 通过结构化 RPC 与事件桥接同步会话和任务状态，处理取消连接后的迟到回包、任务状态乱序、抽屉与弹窗焦点管理。
- 优化虚拟文件列表的响应式数据结构，在双栏各 10 万文件、生产资源和强制 GC 的受控测试中，将前端 JS 堆中位数从 142.28 MiB 降至 34.07 MiB，降低约 76%。

简历中选择最贴近投递岗位的 2–3 点，按自己实际负责且能解释的工作表述。GitHub 地址在仓库创建后补入实际链接；项目周期按真实投入填写。

## 面试时可展开的技术点

| 话题 | 结合代码解释 |
| --- | --- |
| 取消连接后为什么还要处理成功回包 | 尝试 ID、当前尝试判断和过期会话主动断开 |
| 为什么 SSH 跳板机要逐跳确认 | 每条独立 SSH 连接的身份、认证与错误归属 |
| 快速终端输出如何控制内存 | 有界未确认字节、写入完成确认与关闭唤醒 |
| 传输失败如何保护原文件 | 暂存、备份、提交阶段记录与恢复冲突检查 |
| 为什么虚拟滚动后仍可能占很多内存 | DOM 数量与数据响应式代理是两个不同的开销来源 |
| 76% 是怎样测出来的 | 同机同引擎、相同数据量、生产资源、三轮中位数和明确测量口径 |
| 自动化测试覆盖了什么 | 真实本地协议测试、桥接模拟界面测试，以及真实服务器兼容性的边界 |

## 表述边界

已验证的是 macOS Apple Silicon 本机桌面和隔离测试，不写成三平台正式发布或生产大规模落地。传输支持中断后的原文件恢复，不写成断点续传。76% 指定场景下的前端 JS 堆，不能写成整个客户端总内存降低 76%。目前没有线上用户量、业务收益或远程 CI 成功数据，不填造这些指标。
