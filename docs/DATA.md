# 配置、凭据与传输恢复

## 数据目录与导入

软件名称为 `ssh-go`；为延续现有配置，应用标识继续使用 `dev.worklane.ssh.go`，macOS 数据位于 `~/Library/Application Support/dev.worklane.ssh.go/data/`。使用独立目录与原 Worklane、Rust 参考版并存，不会自动读取或覆盖旧数据。

数据目录包含 `state.json`（主机、指纹、偏好设置和加密凭据）、`key`（本地 AES-256-GCM 密钥）和 `recoveries.json`（中断传输记录）。目录权限为 0700，状态文件和密钥为 0600。完整备份需要保留整个目录；备份包含密钥，应作为敏感数据保管。缺少密钥或数据损坏时会报错并保留原文件。

迁移连接时，从旧版导出版本 1 的连接 JSON，在本软件“设置 → 导入 JSON 配置”预览并导入。JSON 不包含密码、私钥口令、私钥内容、系统缓存和服务器信任记录；首次连接时重新输入凭据并核对指纹。SSH Agent 使用当前桌面进程的 `SSH_AUTH_SOCK`。

OpenSSH 导入支持 Host、HostName、Port、User、IdentityFile、ProxyJump 和通配符的首值规则。不会执行 ProxyCommand、Match exec 或展开 Include；不支持的选项会在预览中提示。ProxyJump 仅支持本次配置中定义的单个别名，可通过别名配置链式跳板机。

## 传输与恢复

文件和目录先写入目标目录中的 `.worklane-<任务 ID>.part`，完成后再提交。覆盖普通文件前会将原文件移至 `.worklane-<任务 ID>.bak`，并持久化每个阶段。正常完成会清理备份和记录；崩溃或提交失败时可在“传输队列 → 中断传输处理”恢复原文件或清理临时文件。

恢复原文件仅在最终路径不存在时进行；清理临时文件保留最终文件和原文件备份。远端恢复需要重新连接相同主机与相同连接身份。此功能不提供断点续传，重试会重新传输。

不传输符号链接或特殊文件，不合并或覆盖现有目录。删除目录仅删除空目录。本地提交使用不替换现有目标的重命名；远端普通文件在服务器支持时使用硬链接实现不覆盖提交，否则使用标准 SFTP rename；远端目录提交依赖服务器正确实现 SFTP rename 的不覆盖语义。每个应用最多同时执行 4 项传输，最多 128 项待处理任务。


## 外观偏好

“设置 → 外观模式”提供亮色、深色与跟随系统。首次使用默认亮色；跟随系统会监听系统外观变化。桌面端将 `appearance.mode` 保存到 `state.json` 的偏好设置中，并缓存到 WebView 的 `ssh-go.appearance.mode`，在界面挂载前应用上次选择。网页预览只保存在浏览器本地。

快速切换按顺序保存，启动时较晚返回的偏好不会覆盖刚做出的选择。切换配色不重新建立 SSH / PTY，不修改终端内容、连接凭据或传输任务。
