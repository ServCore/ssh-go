## 尚未验收 / 限制

- 尚未连接用户的真实服务器；服务器特有的认证和 SFTP 行为需要实际环境验收。
- 尚无签名公证与安装分发流程；当前是本机自签名开发包。
- Windows / Linux 桌面未验收；非 macOS / Linux 的目录提交暂不支持。
- 传输不提供断点续传，不合并目录，不传输符号链接和特殊文件。
- 远端目录提交依赖服务器的标准 SFTP rename 语义；Go 主进程资源采样不包含 WebView。

## 内存优化

- 文件目录改为浅层响应式快照，选择集合按整体替换，文件面板间传递选项也保持浅层状态；避免对屏幕外的全部文件建立响应式代理与依赖。
- 搜索与排序条件每次计算只读取一次；未选择文件时不扫描目录来生成选中项。
- 设置、编辑、认证、转发、传输队列、命令搜索以及弹窗组件按需加载。
- 生产资源测试中，本地 / 远程各 10 万项目录的前端 JS 堆中位数从 142.28 MiB 降至 34.07 MiB（76.1%）；空闲桌面占用未测得显著下降。详情、原始数据位置与复现命令见 [MEMORY.md](MEMORY.md)。
